# Changelog

## 1.3.2

- Save custom filter colors in three reusable presets. Built-in colors use their names, and other colors use their slot numbers.
- Load or reset presets from the color picker. Tap a selected palette color again to clear the selection.
- Keep preset controls visible while entering a hex color on smaller screens.
- Remember whether the filter color card is expanded and synchronize dimming controls with the Quick Settings tile and widget.
- Refine the home screen widget
- An in-depth automated security review, followed by privacy and security improvements.

## 1.3.1

- Fixed a bright strip near the camera cutout when dimming full-screen apps.
- Made Darken’s notification optional on Android 13 and newer. Existing notification permissions carry over on update.
- Gave the Quick Settings tile a monochrome icon based on the Darken logo.
- Replaced the Settings icon on the main screen with a symmetrical gear.
- Simplified the privacy policy dialog by removing its duplicate dismiss button.

## 1.3.0

- Added Simplified Chinese UI translation
- Synchronized notification dimming controls with the open app
- Stopped the overlay when the app is dismissed from Recents
- Made the status card toggle dimming
- Show a rainbow swatch for the inactive custom color option
- Added F-Droid metadata and Gradle distribution checksum

## 1.2.7

- Custom color: rainbow swatch opens a hue slider for a wider choice of tints
- Live color preview while dragging the slider; choice is saved when you release
- Hex field: fixed `#` prefix, uppercase digits, smoother typing
- Fix: hue slider no longer jumps to the start at the far right
